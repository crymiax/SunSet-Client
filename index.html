Minecraft, on Linux.

SunSet is a standalone Minecraft: Java Edition launcher written in C++. It downloads the game, picks a Java runtime, lets you set RAM, and runs natively on X11 and Wayland.

Linux x86_64 · X11 / Wayland · C++

What it does

Everything before you press Play: game files, Java, memory and launch arguments.

Linux display
Native X11 and Wayland support. Detected at runtime, or forced with a launch flag.
Versions
Downloads game versions along with the libraries, assets and native files they need to launch.
Java
Picks a suitable Java version for the Minecraft version, or uses a path you give it.
Launch options
Set memory allocation and add extra JVM arguments.
Accounts
The project documents Microsoft device-code sign-in and offline accounts. Microsoft sign-in is still subject to the Azure app-verification status above.
Local data
Stored in ~/.local/share/sunset-client/, as documented in the README.

Use the mod for now

Microsoft sign-in depends on Azure ID verification, so the launcher download isn't a working setup yet. Keep playing with the SunSet mod in your normal Minecraft setup.

  1. Open your Fabric instance. Use the installation or profile where you already run Fabric mods.
  2. Install the SunSet mod. Put the mod JAR in that instance's mods/ folder, along with any dependencies the build needs.
  3. Launch Minecraft as usual. Start the Fabric profile from your normal launcher, not the standalone SunSet launcher.

No mod download is linked here because one isn't listed in the public launcher repository.
