SunSet is a standalone Minecraft: Java Edition launcher written in C++. It handles game downloads and Java selection, with RAM controls and native X11 / Wayland support.

What it handles

The parts before
you press PLAY.

Download the game files, pick the Java runtime, tune memory and launch arguments. The rest is still Minecraft.

01 / DISPLAY

Made for Linux

Native X11 and Wayland support, selected automatically or chosen with a launch flag.

02 / VERSIONS

Version handling

Download game versions and the libraries, assets and native files needed to launch them.

03 / JAVA

Java, your choice

Let SunSet select a suitable Java version for the Minecraft version, or specify your own Java path.

04 / MEMORY

Launch tuning

Adjust memory allocation and add extra JVM arguments for your own setup.

05 / ACCOUNTS

Account modes

The project documents Microsoft device-code sign-in and offline accounts. Microsoft account access is still subject to the current Azure app-verification status.

06 / LOCAL DATA

Local configuration

Launcher data is stored in ~/.local/share/sunset-client/, as documented in the README.
